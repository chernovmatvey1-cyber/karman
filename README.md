# Карман

Полка для файлов на macOS. Схватите файл, скриншот или картинку и резко поводите
курсором туда-сюда: рядом появится полка. Бросьте на неё, а потом заберите всё разом.

## Возможности

- Полка появляется каплей из центра, будто выныривает из экрана, и так же тонет обратно. Если отпустить файл мимо полки,
  пустая полка сразу исчезает; полка, на которую что-то бросили, остаётся.
- Встряхивание только во время перетаскивания (можно включить всегда), три уровня чувствительности.
- Мгновенные действия: пока несёте файл над полкой, внизу появляются плитки
  «Текст» (распознать и скопировать текст со скриншота), «Без фона», «16:9» (умная обрезка
  вокруг главного в кадре), «Сжать».
- Редактор обрезки: 16:9, 9:16, 4:3, 1:1, 3:2 или свободно; рамка сама встаёт вокруг главного,
  её можно двигать, тянуть за углы и стороны или нарисовать заново. GIF обрезаются покадрово и остаются анимированными.
  Можно бросить на плитку и то, что уже лежит на полке.
- Клик по стопке раскрывает все объекты сеткой: любой можно вытащить, выделить (⌘/⇧-клик), убрать.
  Внизу панель функций, они работают с выделенным или со всем сразу.
- GIF сохраняются как GIF и анимируются прямо на полке.
- В меню полки ⌄ ещё: PDF, ZIP, AirDrop, скопировать путь.
- ⌃⌥D — полка под курсором, ⌃⌥S — скриншот области сразу на полку.
- Принимает файлы, папки, миниатюру свежего скриншота, картинки из браузера и Превью, ссылки, текст.
- Стопка с превью или список с размером и типом; любой объект можно вытащить по одному.
- Пробел — быстрый просмотр, ⌘V — вставить, ⌘C — скопировать, Esc — закрыть.
- Меню полки: открыть, показать в Finder, поделиться, сохранить в папку, добавить последний скриншот.
- Несколько полок сразу, перетаскивание между полками.
- Полки переживают перезапуск. Видна поверх полноэкранных приложений.
- Без сети, без аккаунтов.

## Сборка

```sh
scripts/build-app.sh            # build/Карман.app
scripts/build-app.sh --install  # и поставить в /Applications
```

Нужен Swift (Command Line Tools), macOS 14+. Иконку рисует `scripts/make-icon.swift`.
