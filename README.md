# Карман

Карман для файлов на macOS. Схватите файл, скриншот или картинку и резко поводите
курсором туда-сюда: рядом появится карман. Бросьте всё туда, а потом заберите разом.

Без сети, без аккаунтов, всё обрабатывается на самом Mac.

## Возможности

- **Встряхивание.** Карман появляется, когда трясёте курсор с файлом (можно включить всегда).
  Три уровня чувствительности. Отпустили файл мимо — пустой карман исчезает.
- **Быстрые действия.** Пока несёте файл над карманом, внизу появляются плитки:
  «Текст» (распознать и скопировать текст со скриншота), «Без фона», «16:9» (умная обрезка
  вокруг главного в кадре), «Сжать».
- **Редактор обрезки.** 16:9, 9:16, 4:3, 1:1, 3:2 или свободно. GIF обрезаются покадрово
  и остаются анимированными.
- **Стопка и сетка.** Клик по стопке раскрывает объекты сеткой: вытащить, выделить, убрать.
  Ещё: PDF, ZIP, AirDrop, скопировать путь, сохранить в папку.
- **Принимает** файлы, папки, миниатюру свежего скриншота, картинки из браузера и Превью, ссылки, текст.
- **Последние копирования.** Карман помнит 10 последних ⌘C: текст, картинки, файлы.
  ⌃⌘V — список у курсора: выбрали (или нажали 1–9) — оно снова в буфере, осталось нажать ⌘V.
  С ⌥ — положить в карман. Тот же список есть в самом кармане: кнопка-буфер сверху;
  клик по записи — скопировать снова, запись можно перетащить куда угодно.
  Пароли из менеджеров паролей не запоминаются, история живёт только до выхода из приложения.
- **Несколько карманов** сразу, перетаскивание между ними. Карманы переживают перезапуск
  и видны поверх полноэкранных приложений.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| ⌃⌥D | Карман под курсором |
| ⌃⌥S | Скриншот области сразу в карман |
| ⌃⌘V | Последние копирования (работает и ⌃⌥V) |
| Пробел | Быстрый просмотр |
| ⌘C / ⌘V | Скопировать / вставить |
| Esc | Закрыть |

## Сборка

Нужны macOS 14+ и Swift (Command Line Tools).

```sh
scripts/build-app.sh            # build/Карман.app
scripts/build-app.sh --install  # и поставить в /Applications
```

## Устройство

```
Sources/Karman/
  AppDelegate.swift    меню в строке состояния, жизненный цикл карманов, сохранение
  ShakeDetector.swift  распознаёт встряхивание курсора
  Pocket*.swift        модель кармана, его окно, интерфейс и объекты
  Actions.swift        текст, фон, сжатие, PDF, ZIP, AirDrop
  Crop*.swift          умная обрезка и редактор
  ClipboardHistory.swift  последние копирования
  Screenshots.swift    скриншоты, HotKey.swift — горячие клавиши, Settings.swift — настройки
scripts/
  build-app.sh         сборка .app
  make-icon.swift      рисует иконку
```
